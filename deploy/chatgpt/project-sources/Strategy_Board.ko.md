# InvestKitchen 전략 보드 공통 규격

버전: 2026-11-16.1 · 특정 계좌·숫자·시장 상황을 포함하지 않는 출력 계약

여러 계좌·예산·시나리오·진입 조건·시간 대응이 얽힌 질문에 사용한다. 단순 사실
질문에는 강요하지 않는다. 현재 판단, 보드가 성립하기 위한 사전 확인, 독립된
진입 조건, 시나리오, 시간별 행동, 계좌별 배치, 예산·유보, 반대 상황과 거래하지
않는 조건을 필요한 범위에서 읽히게 만든다. 고정 구획·표 순서보다 현재 질문의 판단을
우선한다. 표를 채우기 위해 없는 가격이나 수량을 만들지 않는다.

첫 요약에는 현재 판단 상태·핵심 확인 조건·허용 예산·계좌 제약·가장 강한 무효화를
필요한 깊이로 표시한다. GO/WAIT/STOP 같은 레이블은 설명을 압축할 수 있으나 필수
문구는 아니다. 실제로 확인되지 않은 게이트는 통과가 아닌 미확인이다.

가격·수급·시장 폭·거시·섹터 상대 강도는 확보한 근거로 각각 판단한다. 미확인은
미확인으로 표시하고 반드시 중단해야 하는 조건을 따로 드러낸다. 종목 하나의 강세를
시장 전체 확인으로 바꾸거나 서로 다른 조건을 단일 가격의 자동 매수 규칙으로
압축하지 않는다.

정상 눌림 뒤 회복, 눌림 없이 높은 구간에서 안정되는 경우, 돌파 실패, 다른 섹터로의
순환은 필요한 경우 서로 다른 시나리오로 표시한다. 상호 배타적인 주문을 한 사다리에
누적하지 않는다. 가짜 돌파 후 재진입은 새로운 확인 조건으로 판단한다. 조건을
충족하지 못하는 수직 상승에 예산을 쓰기 위한 논리를 만들지 않는다.

높은 구간의 안정화를 검토한다면 높아진 진입가로 손익비·새 무효화·허용되는 탐색 규모를
다시 계산한다. '작게 산다'는 말로 불리한 조건을 감추지 않는다. 가짜 돌파 뒤 하락 멈춤,
높은 저점, 회복과 새 거래량/수급은 확인 후보의 예이며 정해진 순서를 자동 매수 신호로
만들지 않는다. 현재 시장·계획이 요구하는 조건을 실제 관측으로 판단한다.

시간이 중요한 한국 주식 질문에는 KST 구간을 표시하되, 관측하지 않은 가격 경로나
관행적 시간표를 시장 법칙으로 제시하지 않는다. 장중·종가 분할이 중복되지 않는지,
이미 사용한 예산이 차감됐는지, 같은 신호가 두 번 반영되지 않는지 검토한다.
오후 분할이 종가 분할의 대체라면 두 배로 계산하지 않고 대체 관계를 명시한다.
다른 시장에는 그 시장의 세션·시간대를 사용한다. Core/Tactical 같은 역할과 진입 제한은
현재 Policy/Plan에서 확인하고, 방법론의 예시 시간·후보 수·비율을 개인 규칙으로 만들지 않는다.

관련 계좌마다 역할, 대상, 금액/수량 범위 또는 산정 불가 사유, 조건, 현재 행동을
표시한다. 가용 현금이 가장 큰 계좌의 유지·유보·관찰도 빠뜨리지 않는다. 총현금,
주문 가능액, 현재 정책이 허용하는 전술 예산은 다르다. 핵심 계좌의 현금으로 전술
손실을 메우는 등 허용되지 않은 자금 전용을 제안하지 않는다.
섹터·경제 노출은 전체 포트폴리오 수준에서도 점검한다. 각 계좌의 역할이 다르면 모든
계좌를 같은 구성과 비중으로 맞출 필요가 없다.

거래하지 않는 조건도 완결된 대응이다. 신호 불발, 손익 조건 악화, 자료 부족,
돌파 실패, 거시적 중단 조건을 표나 짧은 블록으로 보이게 한다. ETF 노출은 이름만으로
분류하지 않고 구성 확인 범위에서 직접 보유와의 중복·공통 경제 동인을 구분한다.

보드는 기본적으로 일시적이다. 자세한 보드를 작성했다는 이유만으로 Policy·Plan·
Decision·Transaction을 저장하거나 주문하지 않는다. 저장이 요청되면 별도 도메인의
승인된 절차를 진행한다.
