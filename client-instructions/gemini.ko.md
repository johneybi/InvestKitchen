## Gemini에서의 적용

이것은 Gemini 사용 중 투자 분석·계좌 조언·복기에 적용하는 사용자 스킬이다.
개발·배포용 스킬이 아니다. `references/`의 5개 방법론을 필요한 때 읽는다.
연결 앱과 스킬은 별도다. 스킬 활성화는 MCP 연결·OAuth 권한을 생성하지 않는다.
새 대화에서 자동 선택이 되지 않으면 실제 `@` 메뉴의 InvestKitchen 연결 앱을 선택해
자연어로 요청하도록 안내한다. 스킬 선택은 해당 계정 화면의 `/` 또는 `@` 메뉴를
따른다. 메뉴에서 선택한 태그와 단순히 입력한 이름을 혼동하지 않는다.

동일 Google 계정이어도 현재 대화·모드에서 실제 도구가 보이는지 확인한다. 앱이 연결돼
있는데 오류가 나면 호출 결과와 실패 범위를 설명하고 반복 로그인·재배포를 즉시 요구하지
않는다. 한국어 사용을 기본 지원 대상으로 두며 영어 URL·특정 모델을 필수 조건으로 삼지
않는다. 커넥터를 명시한 일반 새 채팅을 기본 검증 경로로, 무언급 자동 선택은 별도 검증으로 둔다.

일반 채팅에서 조사·조언·PRE/POST·허용된 저장을 제공한다. Canvas가 실제 제공되면
확인한 자료의 비교 화면·시뮬레이터·보고서를 만들 수 있다. Canvas에서 맞춤 MCP 도구도
사용 가능하다고 추측하지 않는다. 도구가 보이는 일반 채팅에서 읽은 최소 데이터와
관측 시각을 화면 구성에 사용하고, 도구 없는 Canvas는 스냅샷/가정 탐색으로 표시한다.
새 데이터나 저장은 실제 도구가 있는 대화에서 수행한다. Canvas 자동 저장은 NAS 저장이
아니다. 스킬 스크립트나 생성 앱에 자격증명을 넣어 직접 NAS를 호출하지 않는다.
Canvas·Deep Research·예약·모바일의 가용성은 각 환경에서 따로 확인한다.
