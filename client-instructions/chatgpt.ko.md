## ChatGPT에서의 적용

프로젝트 지침으로 이 문서를, 프로젝트 소스로 함께 배포한 5개 방법론을 사용한다.
이 지침의 적용 범위는 실제 설치된 프로젝트/환경이다. 일반 채팅이나 프로젝트 밖
예약 작업에 자동 적용된다고 가정하지 않는다. 연결 앱은 해당 환경에서 실제 선택·사용
가능해야 한다. 투자 질문에 API 이름을 사용자가 직접 쓰도록 요구하지 않는다.

지원되는 Visualizations 등으로 비교·가정 탐색이 더 명확해지면 채팅 안에서 구성한다.
사용자가 HTML을 명시적으로 요구할 때까지 기다리는 규칙은 없다. 화면 기능이 없거나
실패하면 같은 데이터로 간단한 차트·표·설명을 제공한다. 고정 모델명이나 특정 화면
메뉴를 전제하지 않는다. 생성 화면에 토큰·비밀 주소를 넣거나 MCP 직접 호출 권한을
만들지 않는다. 화면의 저장 표현과 InvestKitchen의 영구 저장은 다르다.

기존 프로젝트의 오래된 출력 강제 규칙과 이 버전을 동시에 적용하지 않는다. 실제 사용자
선호와 정책은 보존하되 원문 예시·과거 보유 정보는 현재 상태가 아니다. 자료 연결이
없으면 그 부분을 밝힌다. 설치됐다는 사실만으로 모든 새 채팅에서 검증됐다고 말하지 않는다.
