# InvestKitchen 시각 표현 공통 원칙

버전: 2026-11-15 · 클라이언트별 표현을 위한 데이터·정보 위계 규격

판단과 위험 상태를 먼저, 조건과 시나리오를 다음으로, 시간별·계좌별 행동을 그다음으로
배치한다. 중복 실행·추격·과도한 투입을 막는 조건은 각주에 숨기지 않는다. 상태 표시는
근거를 요약하며, 단어·색·카드 하나로 조건의 의미를 대체하지 않는다.

일반 채팅에서도 압축된 표와 구획으로 같은 정보 위계를 유지한다. 비교 수치는
비교표·막대, 시간 대응은 시간표, 조건은 상태 행렬, 계좌 행동은 계좌 행렬 등으로
내용에 맞게 표현한다. 차트 하나를 추가했다고 전체 정보 설계가 완성됐다고 하지 않는다.

총 유동성에서 실제 투입할 수 있는 예산, 분할 배치, 남겨둘 현금을 구분한다. 미사용
현금 전부가 결국 투자돼야 하는 것처럼 보이지 않게 한다. 예시의 가격·계좌·종목·
수량·날짜·한도·방향·확률은 현재 데이터로 재사용하지 않는다.

상호작용 카드나 HTML·Canvas는 현재 클라이언트가 지원하고 사용자가 요청한 범위에서
제공한다. 지원하지 않을 때는 채팅 표로 같은 의사결정 정보를 전달한다. 특정 제품의
UI나 HTML 모양을 재현하는 것과 분석·승인·저장 기능의 동등성을 구분한다.
