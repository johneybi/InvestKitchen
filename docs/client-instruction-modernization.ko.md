## 원문에 부족했던 항목도 추가

- 한 요청의 분석·개인 조언·PRE/POST·기록을 함께 처리한다. 단일 workflow 라우팅만으로 끝내지 않는다.
- 생성 화면의 스냅샷·가정 변경·실제 상태 변경과 Canvas 저장을 구별한다.
- 한국어 새 채팅·앱 선택·다른 PC·모드별 도구 가용성을 독립 검증한다. 영어 URL은 필수 규칙이 아니다.
- 두 사용자 패키지는 같은 원본과 상세 소스로 생성하고 버전/해시로 편차를 검사한다.
- 401·연결 종료·빈 자료·미노출 도구를 구분한다. 클라이언트 답변만으로 서버 원인을 단정하지 않는다.
- 정확한 기록 조회·적용 여부 불확실·검증 대기와 원문 보관을 각각 보고한다.

## 이번 후보가 구현하지 않은 기능

영구 Reflection 수명주기·개인 분석 이력과 연결·실제 지속 관찰/알림·추가 금융 데이터
공급자·승인 횟수를 줄이는 서버 계약은 지침 문구만으로 구현되지 않는다. 이 항목들은
제품 계획에 남기고 현재 기능으로 광고하지 않는다. 승인된 변경의 정확한 적용과 인증
검증은 그대로 유지한다. 웹 행동 평가 결과는 [별도 시나리오](client-experience-acceptance.ko.md)에 기록한다.
